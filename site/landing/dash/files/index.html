FastRSI: Unblock the evaluation bottleneck for RSI

TLDR: FastRSI is an agentic framework that reduce evaluation overhead to accelerate RSI. FastRSI first make a system "live-editable" such that changing a few lines of code in-place do not need to restart the engine. Then, FastRSI encourage agent to develop "targeted probes" so that a cheaper but verifiably stable evaluation can deliver strong signal of improvement. We show that FastRSI reaches final result — – — sooner when provided to ML system tasks, and show even better speedup as the token generation speeds up.
