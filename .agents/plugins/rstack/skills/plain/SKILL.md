# Plain-Language Translation (`/plain`)

Translate dense systems prose, benchmark tables, PR reviews, or error logs into clear, honest everyday English without losing measured precision.

1. **Drop Internal Shorthand**: Replace internal symbol names, tier codes (`R0`, `R1`), and acronym stacks with what the user or hardware actually experiences.
2. **Keep Numbers Exact**: Preserve real timings, memory counts, and failure boundaries; never invent rounded ranges or omit caveats (`Not verified`, CPU-only scope).
3. **Lead With the Concrete Action**: State what broke, what changed, what was measured, and what stays risky in short plain sentences.
4. **Verify Against Source**: Ground every claim directly in the cited code, doc, or command output (`pstack` `/bro` style clarity).
