# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in `rsibox` (for example, sandbox escape, unsafe code execution in workflows/launchers, or credential leakage), please report it privately via **GitHub Security Advisories** ("Report a vulnerability" under the repository's **Security** tab) rather than opening a public issue.

Please include:

- A clear description of the issue and affected files or workflows.
- Minimal reproduction steps or proof of concept.
- Any suggested mitigation or fix, if known.

We will acknowledge reports promptly and coordinate a fix before public disclosure.
